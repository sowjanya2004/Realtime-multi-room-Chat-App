# 💬 Realtime Multi-Room Chat Application

A real-time, interactive multi-room chat application where users can join topic-based chat rooms and communicate instantly. Built with Node.js, Express, and Socket.io, it delivers smooth and efficient messaging functionality, providing an engaging and seamless chat experience.

---

## 🚀 Features

- Create or join multiple chat rooms based on topics, tech-language, or interest.
- Real-time messaging powered by WebSockets for instant communication.
- Instant notifications when users join or leave the chat room.
- Time-stamped messages with room-level segregation for better organization.
- Auto-scroll and a clean, user-friendly interface for smooth chatting.

---

## 🛠️ Tech Stack

### 📦 Backend

- **Node.js**
- **Express.js**
- **Socket.io**

### 🎨 Frontend

- **HTML** – Semantic layout and structure
- **CSS** – Responsive custom styling
- **JavaScript** – DOM manipulation and WebSocket event handling with Socket.io client
